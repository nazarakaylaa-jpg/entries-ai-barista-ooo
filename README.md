## The entry

> "I am out of office — I have traded my inbox for an espresso machine. Your email is queued behind 12 oat lattes; expected response time is one flat white, or never."

## How it works

`main.ts` writes the one-line out-of-office auto-reply (163 characters, a single line, punchline at the end) to `/output/entry.txt`. Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
